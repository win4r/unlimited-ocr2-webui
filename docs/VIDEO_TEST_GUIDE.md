# YouTube 浏览器实测指南

新版界面已能支持上传、原图与结果对照、长文档连续性检查、Base/Gundam 对比、运行过程录制和数据导出。它提供实测工具；模型准确率仍需要你准备真实样本和人工参考答案。

## 一次可复核的演示

1. 打开 HTTPS 入口并刷新，运行一次原创示例，确认“模型就绪”和资源采样正常。如果讨论预热后的性能，先完成一次预热，给正式任务备注“已预热”。不要把首次编译耗时混入后续性能结论。
2. 固定 PDF DPI、页码、每页输出上限与模式，填写材料类型、预热状态等备注。原图分辨率会显示在左侧。低清扫描、密集表格、双栏、公式、旋转或模糊图像可分别作为挑战样本；每类的结论只覆盖实际测试的材料。
3. 开始解析后点击右上角“录屏模式”。上方显示资源和过程，下方保留原图与结果。按 Esc 返回普通模式，上传区、历史、对照表和文字核对区恢复显示。
4. 选择“跟随当前页”，切换左侧页码，逐页检查错字、漏行、阅读顺序与布局框。需要看跨页拼接时切回“整篇合并”，同时检查 Markdown、原始输出和最后一页。进度按已经结束输出的页数计算，不代表该页内容正确。
5. 完成后点击“同图重跑 Base/Gundam”。页面缓存原样复用，输入 SHA-256 相同才标为同输入；对照表自动展开。主要比较“推理请求耗时”，因为第二次复用 JPEG 不再花费原先的 PDF 渲染时间。当前没有自动多轮统计，重复测试可继续点击重跑，再导出总表计算中位数与波动。
6. 展开“人工参考文本核对”，选择当前页或整篇，粘贴相应的人工参考答案。检查自动提取的识别文字后计算 CER。参考内容需完整对应所选范围，包括页面标题、页码等实际参与提取的文本；不要用模型自己的结果冒充参考答案。
7. 下载资源 CSV、运行指标、文字核对 JSON、Markdown 和完整 ZIP。右上角“导出实测总表”汇总服务器保留的任务，含文件名与备注；公开展示或分享前自行选择需要的测试任务。

## 数据如何解释

| 项目 | 当前口径 |
| --- | --- |
| 上方资源数字 | 服务器当前状态；打开历史任务也会继续更新 |
| 所选任务曲线 | 从任务开始执行到结束，约每秒记录；最多显示最近 180 点，CSV 保留全部 |
| 实时曲线 | 当前 Web 服务进程内最近的服务器样本；与任务曲线可切换 |
| 显存 | 整张 GPU 的已用显存，包括 SGLang 预留池、CUDA Graph 和其他进程；不是该文档独占显存或 KV 缓存大小 |
| RAM | 全机总内存减可用内存，不是单独的 Web 或模型进程内存 |
| CPU | 全机总利用率，0–100%，不按每个核心分别相加 |
| 峰值与增量 | 1 秒采样最大值，以及相对本任务开始前最近一个样本的增量；可能漏掉瞬时峰值，不能据此推导最低硬件需求 |
| 任务耗时 | 从执行队列开始工作计时，包含页面准备与模型请求，不含上传和排队 |
| 推理请求耗时 | Web 发起模型请求到响应流结束的时间，包含模型端排队、视觉预处理、预填充与生成等；不是纯解码时间 |
| 首内容 token 等待 | 从发起请求到收到第一段非空内容的时间，包含服务器处理与传输；不是 GPU 内核级 TTFT |
| 请求综合吞吐 | 服务实际上报的 completion tokens ÷ 推理请求耗时，包含布局标记；不是纯解码速度 |
| 实时字符流速 | 近约 3 秒收到的原始输出字符数/秒，包含布局标记；不当作 tokens/s |

长文档的定制 SGLang 路径可能在结束时才上报 tokens。此前界面显示“待服务上报”，同时展示真实字符进度。图表的 baseline 与 finish_cached 行复用最近样本，并非额外独立的 GPU 测量；CSV 的 sample_kind 有明确标记。旧任务的资源历史与新版精确计时无法补采，需重新运行；对照表会提示缺失或计时版本不同。

## 准确率边界

CER =（替换 + 删除 + 插入）÷ 人工参考字符数，越低越好，插入很多时可超过 100%。默认忽略所有空白字符，但保留标点、大小写；也可关闭忽略空白。单次参考与识别文字各最多 20,000 字符，长文档按页核对。

文字提取会去掉布局标记和图片块，将表格转为单元格文本，公式保留 LaTeX。CER 不评价表格结构、合并单元格、阅读顺序、公式语义或跨页拼接质量。这些需结合原图、Markdown 与原始输出人工检查；本界面未实现 TEDS、公式等价判定或正式数据集自动跑分。原创示例通过只证明部署链路和对应样本行为，不代表所有语言、手写、古籍或扫描条件都可靠。

## 升级与恢复

服务器更新 Web 代码前使用 `.venv/bin/python scripts/safe_restart_web.py`，暂停新任务并等待已有任务结束。失败或取消任务保留完整页面缓存时，可“使用原模式恢复”，不必重新上传。完整任务 ZIP 不包含原始上传文件；页面源文件仍在服务器 `runs/`，请根据需要另外保存原文档。复用部署包不包含用户上传文档、登录密码或模型权重。
